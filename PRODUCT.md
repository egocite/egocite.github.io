## Platform

web

## Users

The primary audience is academic reviewers and researchers evaluating EgoCITE. They need to understand the paper's problem, method, evidence, and quantitative results quickly, then inspect detailed methodology and experiment data when needed.

## Product Purpose

This project page presents EgoCITE, a long-horizon agentic memory framework for egocentric question answering. Success means that a first-time reader can identify the paper's contribution, understand how EgoScheme, EgoIndex, and EgoRetrv work together, verify the main experimental findings, and reach the paper, code, or citation entry when those resources are available.

## Positioning

EgoCITE jointly addresses context-poor memory indexing and retrieval that ignores a question's temporal intent. Its mechanism combines context-augmented atomic memory index construction, multi-view egocentric memory indexing, and time-aware retrieval and curation.

## Operating Context

The page is a static academic project website hosted on GitHub Pages. Readers may arrive from a paper link, search result, repository, or conference review workflow and use it on desktop or mobile. The page supports overview reading, methodology exploration, interactive experiment inspection, trace-level examples, and temporary BibTeX access.

## Capabilities and Constraints

- Preserve paper-grounded terminology, claims, metrics, examples, and quantitative values.
- Preserve the working methodology selectors, retrieval-stage controls, trace examples, experiment tabs, interactive charts, responsive tables, keyboard navigation, and public GitHub Pages deployment.
- The visual system and page structure may be replaced or partially reorganized when doing so improves comprehension.
- Paper and code links remain honest placeholders until real destinations are supplied.
- Do not invent results, explanations, people, datasets, baselines, or method behavior.
- Avoid excessive cards, excessive whitespace, and small or inconsistent text.

## Brand Commitments

- Preserve the EgoCITE name and smart-glasses mark.
- Preserve the overview figure's blue and yellow identity as the governing palette.
- Use the paper's own technical vocabulary instead of adjacent or invented marketing language.
- Maintain a professional academic tone appropriate for reviewers and researchers.
- Match the craft level of `https://worldmm.github.io/` and `https://egomemreason.github.io/`: a recognizable academic project page with a clear scholarly identity, compact paper actions, immediate visual evidence, and strong responsive behavior.

## Product Principles

1. Lead with the paper's mechanism and strongest supported evidence.
2. Make overview comprehension immediate and detailed evidence inspectable on demand.
3. Preserve factual fidelity over promotional language.
4. Use interaction to clarify the paper, not decorate it.
