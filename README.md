# EgoCITE Project Page

Academic project page for **EgoCITE: Context-Augmented Indexing and Time-Aware Retrieval for Long-Horizon Egocentric Memory**.

- [Live website](https://egocite.github.io/)
- Paper: arXiv link coming soon

The site is plain HTML/CSS/JavaScript and deploys directly from `main` with GitHub Pages. Its publication-first structure follows the [Nerfies academic project-page template](https://github.com/nerfies/nerfies.github.io), with a blue/yellow visual system derived from the paper overview.

Results figures are responsive Chart.js visualizations backed by the exact values from the paper's plotting scripts, with the original PNGs retained as no-JavaScript and print fallbacks.
